# CalcWeave 디자인 백서

현행 CalcWeave 앱 `0.26.0` / 엔진 `0.17.0-m16`의 화면·상호작용·문구 원칙을 설명한다. 계산 의미와 제한은 [기술 백서](01-technical-whitepaper.md), 실제 관측은 [검증 문서](validation.md), 데이터 보호·배포는 [운영 안내](operations.md)를 따른다. 자동 브라우저 검사·화면 관측을 실제 초보자 연구나 접근성 인증으로 표현하지 않는다.

## 경험의 출발점

사용자가 작은 블럭 세 개를 연결하고 예상한 값을 확인하는 것이 첫 성공이다. 이후 같은 모델을 시간 시뮬레이션, 표 데이터, 재사용 정의, 실험과 프로그램 코드로 넓힌다. 전문 기능을 숨겨 뜻을 바꾸거나, 툴박스와 코드 문법을 첫 사용의 조건으로 요구하지 않는다.

제품명은 **CalcWeave**, 설명은 **블럭으로 연결하는 수학 계산과 시뮬레이션**이다. 로고·아이콘·예제와 화면은 독립적으로 제작한다. 원본 기능 이름을 탐색에 쓰는 것과 Simulink 모델·결과·코드의 호환성 약속을 구분한다. 목표 브랜드 도메인 **CalcWeave.com**과 실제 접속 주소·확인된 공개 버전도 구분한다.

사용자가 요청한 [SANE 디자인 기준](https://github.com/JTech-CO/SANE/blob/main/SKILL-KR.md)을 유지한다. 작업 캔버스의 우선순위, 읽을 수 있는 글자, 중복 정보 제거, 역할 있는 색, 한글·숫자 렌더링과 상태별 검토를 기준으로 삼는다. 과거 별도 수정 기록의 고유 규칙은 이 문서에 통합하고 실제 [SANE 측정 증거](evidence/sane-design-verification.json)는 보존한다.

| 원칙 | 제품에 적용한 결과 |
| --- | --- |
| 작은 성공부터 | 빈 캔버스의 첫 계산 안내와 작은 실행 가능한 예제. |
| 도식이 의미를 설명 | 블럭의 종류·핵심 값·포트·연결 방향이 우선이며 상세 설정은 선택한 속성에 둔다. |

| 복잡성은 점진적으로 | dtype·unit·rate·solver·상태·예산을 접을 수 있으나 현재 적용값과 지원 제한은 확인할 수 있다. |
| 오류는 고칠 위치로 | 노드·포트·파라미터·원본 위치를 보여 주고 관련 블럭을 선택할 수 있게 한다. |

## 정보 구조와 첫 사용

주요 작업은 도식·데이터·실험·대시보드·노트다. header에는 모델명·저장 상태·모델 다운로드/가져오기·코드 다운로드·작업 공간·지원/릴리스가 있고 toolbar는 추가·예제·실행에 집중한다. 작업 공간 메뉴에서 백업·복구를 바로 열 수 있고, 서명된 모델 패키지는 닫힌 고급 파일 안에 둔다. 공개 키 지문이나 저장소 진단을 첫 계산의 필수 단계로 제시하지 않는다. 라이브러리의 범주/검색과 속성 패널은 실제 registry를 따른다. 각 기능의 모드·자료형·타깃 제한은 추가와 실행 위치 가까이에 둔다.

라이브러리의 제목·전체 블록 수·검색은 고정하고 목록만 세로로 스크롤한다. 처음에는 맨 위의 **자주 쓰는 블록** 10개만 펼치고 실제 29개 카테고리는 접는다. 카테고리는 마우스·Enter·Space로 독립적으로 열고 닫으며, 현재 작업에서 라이브러리를 닫았다 다시 열어도 펼침 상태를 유지한다. 검색 중에는 일치하는 카테고리를 자동으로 열고 추천 중복을 제외한다. 검색을 지우면 이전 펼침 상태를 복원한다. 추천 목록의 중복을 전체 337개에 더하지 않는다. 작은 화면에서도 고정된 검색과 세로 목록을 사용한다.

75개 예제를12개 범주로 찾을 수 있다. 제목·설명·사용 블럭 ID의 검색, 범주 선택, 방향키·Enter·Escape와 IME 입력을 구분한다. 예제는 실제 모델 snapshot이며 category label을 추가 블럭이나 독립 엔진 수로 세지 않는다. 첫 계산→시간 입력/상태→연속/혼합→행렬/표/자료형→계층/메시지→데이터/어댑터의 학습 경로를 제공하되 모두 순서대로 학습해야만 기능을 사용할 수 있는 구조로 만들지 않는다.

빠른 추가는 이름·별칭·카테고리로 검색하고 키보드로 선택한다. 버튼에 K나 문자 v 같은 장식 텍스트를 반복하지 않는다. dropdown은 실제 SVG affordance를 쓰고 단축키는 tooltip·접근성 설명·도움말에서 안내한다. 결과가 없으면 검색어를 수정하거나 범주를 넓힐 수 있도록 설명한다.

## 작업 공간과 반응형 배치

넓은 화면의 우선순위는 **라이브러리 | 도식 | 계산 결과 | 속성**이다. 캔버스와 결과를 좌우로 두어 도식과 값의 관계를 동시에 읽는다. 데스크톱 라이브러리·속성의 폭은 기존의 약70%인175/218px, 1700px 이상에서는196/241px다. 결과 열도224~294px로 압축하고 상단 헤더 최소50px·도구막대42px, 작은 버튼과 여백으로 캔버스를 우선 확보한다. 본문16→15.52px·보조 글자14→13.6px로 약3%만 줄이며 대화상자의 보조 글자는14px 이상으로 유지한다. 캔버스의 확대·이동과 노드 배치는 유지한다. 터치 장치의 주요 버튼은40px 이상의 높이를 유지한다. 좁은 화면에서는 라이브러리 접기·패널 전환·대화상자 스크롤로 작업 경로를 보존한다. 현재 responsive breakpoint는 [styles.css](../apps/web/src/styles.css)의 실제 구현을 따른다.

캔버스 안에서 노드·결과·필수 버튼이 가려지지 않게 panel 최소 폭·min-width0·overflow를 검사한다. 긴 한국어 제목·파라미터·diagnostic·typed 문자열·정수 code·bus field·작은 화면의 메뉴를 함께 검토한다. 결과와 table의 상세는 스크롤/펼치기로 볼 수 있어야 하며 잘린 숫자를 전체 결과처럼 표시하지 않는다.

최초 모델 복원·모델/예제 교체·계층 이동은 실제 캔버스 크기와 노드 측정이 안정된 뒤 도식을 한 번 맞춘다. ResizeObserver와 취소 가능한 frame 안정화를 사용하며 늦게 도착한 이전 fit이 새 모델 viewport를 바꾸지 않도록 한다. 일반 편집·실행 중에는 사용자의 확대·이동을 보존한다. fit은 `minZoom/maxZoom`와 읽기 범위에 맞추며 모든 큰 모델을 한 화면에 넣기 위해 글자를 무조건 축소하지 않는다.

## 수식·학습의 읽기 흐름

계산 결과와 진단 옆에 **수식·학습** 탭을 둔다. 캔버스와 같은 도식의 식을 옆에서 읽고, 수식의 항을 눌러 해당 블록을 선택한다. 블록 안의 정보는 늘리지 않으며 실제 이름·단위는 펼칠 수 있는 기호 목록에서 확인한다. 설명 가능한 식과 미지원 안내를 구분하고, 유효하지 않은 숫자 초안을 편집할 때는 이전 값을 새 식처럼 표시하지 않는다.

배율·이산 피드백·연속 감쇠의 세 가이드는 **예측 → 수정 → 실행·관찰 → 설명**의 흐름을 제공한다. 배율·초기값 설정 버튼은 각각 한 블록을 선택해 속성 패널에서 바로 편집할 수 있게 한다. 현재 식의 예상값과 실제 실행을 비교하되 학습 글을 자동 채점하지 않는다. 결과 탭에서 곡선을 본 뒤 돌아와도 예상·설명과 활성 학습을 유지한다. 학습 닫기·다른 예제 열기에서만 메모를 정리한다.

수식 패널은 내부에서 스크롤하고 탭·실행 상태는 위에 유지한다. 일반 본문은15.52px, 수식은18px 기준으로 읽으며 검정·회색 테마와 텍스트 확대를 따른다. 키보드로 수식 항을 선택할 수 있고 선택 상태는 색상과 버튼 상태에 함께 표시한다. 자동 검사와 화면 확인을 실제 초보자 학습성 검증으로 표현하지 않는다.

## Scope 관측의 읽기 흐름

[Scope 화면](../apps/web/src/components/ScopePlot.tsx)은 기본 곡선·성분 선택·커서 원시 기록을 함께 보여 준다. 클릭과 키보드 이동으로 실제 기록을 찾고, 시간 입력·슬라이더·보기 구간 설정은 **시간·구간 조절**에 묶는다. 확대 드래그 범위는 푸른 사각형으로 표시하고 **전체 구간**으로 되돌린다. 보기 구간 조작은 재실행이나 모델 편집을 유발하지 않는다. **시뮬레이션 시간 범위**는 별도 실행 설정으로 남긴다.

실험 화면에서 최대3개의 선택 기록과 공통 출력·성분을 같은 축으로 비교한다. 곡선은 색과 서로 다른 선 모양, 실행 이름을 함께 사용한다. 커서 표는 요청 시각과 각 실행의 실제 샘플 시각·원본 값을 구분하며 취소·실패 기록은 부분 결과로 안내한다. 지원하지 않는 자료형·단위·형상의 조합에는 이유를 보여 준다. 삭제된 기록의 선택은 비교 개수에서 제외한다.

기존 검정·밝은 회색 테마와 읽기 쉬운 글자 크기를 유지하고, 좁은 결과 패널에서 입력과 범례를 줄바꿈한다. 긴 원본 값은 잘라 의미를 바꾸지 않으며 표 안에서 스크롤한다. 그래프 조작 중 Space는 캔버스 도식 맞추기를 실행하지 않는다.

## 다변수 실험과 측정 피팅

실험 탭에서 기존 단일 스윕과 실행 기록을 유지하고 **다변수 실험**, **측정 데이터로 파라미터 피팅**을 접힌 영역으로 제공한다. 숫자 블록을 최대3개 선택하고 전체 조합 수를 실행 전에 보여 준다. 피팅은 계수별 하한·상한·초기값, 측정 CSV의 시간·값 열과 단위를 순서대로 확인한다. CSV를 서버로 보내지 않으며 임의 코드나 HTML로 표시하지 않는다.

후보 계수·RMSE·최대 절대 오차를 먼저 읽고, 같은 축의 측정·예측 곡선에서 차이를 확인한다. 잔차 그래프·원시 표·탐색 과정은 추가로 펼친다. 종료 사유와 부분 결과를 명시하고 전역 최적값을 보장하지 않는다. 실행 중에는 설정 입력을 잠그고 취소를 제공한다. 모델이 변경되면 후보 적용을 차단하고 다시 실행하도록 안내한다. 적용은 한 번의 undo로 되돌릴 수 있다.

보고서 JSON에는 실행 당시 설정을 넣으며, 이후 폼 편집을 과거 실행 출처로 표시하지 않는다. 전체 보고서의 세션 보관과 기존 최근5개 실행 기록 정책을 안내한다. 16px 입력, 좁은 화면의 세로 필드 배치, 테마 색상과 표 내부 스크롤을 유지한다.

## 불확실성 앙상블

실험 탭의 **불확실성 앙상블**을 접힌 영역으로 제공한다. 최대3개 숫자 계수의 분포·하한/상한/최빈값, seed·표본 수·같은 단위의 출력부터 지정한다. 실행 전 숫자 길이·범위·중복을 확인하고 잘못된 초안은 이전 보고서를 유지한다. 유효한 새 실행은 이전 보고서를 지우며 취소·모델 변경·늦은 결과를 실행 세대로 구분한다.

보고서는 요청/시도/완료/실패/취소/미시작 수와 실제 사용량을 함께 표시한다. 취소·시간 초과 때 통계를 제공하지 않을 수 있음을 안내하고 완료 원시 기록은 보존한다. 완료한 실행만 집계한 평균·표본 표준편차·분위수 곡선과 전체 원시 표를 제공하며 표준편차의n−1·분위수의보간·실패 제외로 인한 편향을 설명한다. 분위수 구간을 신뢰구간으로 표시하지 않는다. 전체 계수 표본·진단·원시 결과는 JSON에 보존하며, 폼 편집이나 탭 전환으로 이미 계산한 설정을 바꾸지 않는다.

완료한 표본의 **모델 적용**만 계수를 바꾸며 실행 취소로 복원할 수 있다. 실험 후 모델이 바뀌면 적용을 비활성화하고 이전 출처임을 안내한다. 전체 보고서는 세션에 보관하고 기존 최근5개 실행 이력·백업 정책을 유지한다. 16px 입력·버튼, 작은 화면의 한 열 배치와 내부 원시 표 스크롤을 사용한다.

## 제어계 분석

기존 수치 분석 창의 **제어계 분석**을 접힌 영역으로 제공하고 수식 기울기·solver 해상도 비교를 유지한다. 현재 State-Space 설정과 확인된 실행 선형화의 출처를 구분하고 모델 이름·기록 시각·마지막 요청 시각을 표시한다. 이전 모델이나 부분 실행에서 나온 행렬임을 숨기지 않는다.

Bode 크기·위상, 상태 극점·미약분 전달 영점을 먼저 관찰한다. 개루프·단위 음의 피드백 가정을 사용자가 선택한 경우에만 여유·근궤적을 표시하고 보고서에 포함한다. 여유가 없는 값을 무한대로 대신하지 않으며, 특이점은 빈 구간으로 표시한다. 근궤적은 지정 이득의 점을 보여 주며 불확실한 가지를 이어 그리지 않는다.

원시 주파수·교차·근궤적·행렬 표는 추가로 펼친다. 긴 숫자는 표 내부에서 스크롤하며, 16px 입력·본문과 좁은 화면의 세로 배치를 사용한다. JSON은 폼의 현재 초안 대신 실제 계산한 출처·설정·가정을 보존한다. 잘못 입력한 초안은 이전 보고서를 유지하지만, 유효한 새 분석을 시작하면 이전 결과를 지워 실패한 새 계산과 혼동하지 않도록 한다. 분석은 모델을 편집하지 않는다.

## 이산 제어계 분석

수치 분석 창의 **이산 제어계 분석**을 별도 접힌 영역으로 제공한다. 현재 루트 블록의 행렬과 period·offset·기본 실행 간격·Ts·Nyquist를 표시하며, 연속 분석의 s 평면·허수축 판정과 이산 분석의 무차원 z 평면·단위원 판정을 구분한다. ω는 물리 rad/s의 로그 축이고 π/Ts를 넘는 초안은 거부한다. 단위원은 그래프에 직접 그려 색상만으로 경계를 설명하지 않는다.

기본은 Bode·극점/영점이며 단위 음의 피드백을 선택해야 여유·K 표본을 표시하고 JSON에 포함한다. 주변 다중 rate·버퍼 지연·초기조건을 추론하지 않는 출처 가정을 보여 준다. 폼 편집과 잘못된 초안은 계산한 보고서를 보존하고 유효한 새 계산 시작은 이전 보고서를 지운다. 현재 블록이나 모델 지문이 바뀌면 이전 결과와 주파수 기본 범위를 초기화한다. 16px 입력·좁은 화면 세로 배치·내부 원시 표 스크롤을 유지한다.

## 기록의 신호 스펙트럼

**분석 → 신호 스펙트럼 분석**은 접힌 영역으로 제공한다. 완료한 출력 기록·성분·0부터 센 시작 표본·8~8192의2의 거듭제곱 표본 수를 사용자가 고르고, Hann/직사각형 창과 평균 제거를 선택한다. 기본 구간은 처음최대256개에서 사용할 수 있는2의 거듭제곱 개수이며 실제 입력창에 표시한다. 짧은 실행·정적 계산·부분 실행에는 안내를 표시하고 실행 버튼을 비활성화한다.

선형 Hz 축의 각 막대는 실제 FFT 빈이다. 진폭·PSD를 전환하고 표본 주파수·해상도·Nyquist·원시 평균/RMS·DC 이외의 최대 빈을 함께 읽는다. 창·평균 제거의 영향과 작은 계수의null 위상, 빈 사이를 추정하지 않는다는 설명을 표시한다. 전체 원시 표는128행씩 페이지를 나누고 표 내부에서 스크롤한다. 모든 입력·설명·버튼은16px를 유지하고 좁은 화면에서는 한 열로 배치한다.

현재 폼과 이미 계산한 보고서를 구분한다. 잘못된 표본 초안은 이전 보고서를 보존하지만 유효한 새 계산의 출처·FFT 검증이 실패하면 이전 결과를 제거한다. 모델·기록을 변경하지 않고 실제 출처 모델·표본 SHA-256·설정을 JSON으로 저장한다. 이전 실행은 이전 기록으로 표시하며, 창을 편집한 것만으로 과거 보고서 설정을 바꾸지 않는다.

## 기록의 구간 통계와 상관

**분석 → 시간 구간 통계와 신호 상관**은 접힌 영역으로 제공한다. 사용자는 출력/성분·0부터 센 시작 표본·2~8192개 표본 수를 고른다. 통계에서는 같은 표본 가중치와 N/N−1 분모·원래 단위/제곱 단위를 보여 주며 숨겨진 상관 설정의 초안 오류는 통계 계산을 막지 않는다. 기본 구간은 처음 최대1024개이고 자동 보간·표본 개수 조정은 없다.

상관에서는 X/Y 출력·성분·최대 지연·최소 겹침·평균 제거를 명시한다. 양의 지연은 Y가 X 뒤에 오는 방향이고 평균 제거는 각 겹침마다 수행한다. 실제 겹침 수와 정규화·원시/scaled 수치는128행 표와 JSON으로 읽는다. 그래프는 −1~1 축에서 최대512개 실제 지연을 점으로 표시하며 정의되지 않은 행은 건너뛰고 점 사이를 보간하지 않는다. 표 내부 가로 스크롤과 좁은 화면의 한 열 배치,16px 입력·설명·버튼을 사용한다.

JSON에는 실제 원시 시각·값·선택 구간·단위·모델/표본 SHA와 계산 때의 설정을 담는다. 폼 수정은 기존 보고서를 바꾸지 않는다. 잘못된 초안은 이전 보고서를 보존하고 유효한 새 요청의 출처/계산이 실패하면 이전 결과를 제거한다. 이전 실행은 그 출처를 표시하며 최대 상관을 인과관계나 확정 지연으로 표현하지 않는다. 분석이 모델과 실행 기록을 변경하거나 자동으로 모델을 다시 실행하지 않는다.

## Welch와 시간·주파수 관측

**분석 → 시간·주파수 분석**에서 출력·성분·시작 표본·표본 수·창 길이·겹침·창·구간별 평균 제거를 명시한다. 기본 구간은 처음 최대1024개, 기본 창은 그 구간 안에서 최대256의2의 거듭제곱, 기본 겹침은 절반이다. 끝 구간 제외 정책·실제 사용/제외 표본·hop·구간 수·Δf·작업 예산을 읽을 수 있다. Welch의 평균과 구간별 STFT 원시값을 구별한다.

Welch는 최대512개 실제 빈을 DC/Nyquist/피크를 보존해 표시한다. 열 지도는 최대4096개 실제 구간/빈 셀을 선택하여 표시하고 집계·보간한 값으로 표현하지 않는다. 원시 표는128행씩 보며 STFT 구간 선택은 native select로 키보드에서 조작한다. 구간 축에는 실제 첫/끝 표본의 중점 시각, 주파수 축에는 실제 Hz를 사용한다. 표시용 선택은 전체 보고서나 원시 자료를 줄이지 않는다.

선형 PSD 또는10log₁₀(PSD/[1·(신호 단위)²/Hz])를 선택한다. 단위는 `(m/s)²/Hz`처럼 전체를 묶는다. 정확한0은 dB가 정의되지 않는 별도 중립색/표식으로 남기며 임의 epsilon이나 바닥 값을 넣지 않는다. 색 범위와0의 의미를 범례·표에서 읽고 raw JSON은 항상 선형 밀도를 보존한다. 모든 설명·입력·버튼의16px 최소 글자와 좁은 화면 한 열 배치/표 내부 스크롤을 적용한다.

계산 전에 원시 선택·출처·초안 설정을 캡처한다. 폼 편집이나 이전 실행 표시가 저장된 보고서를 바꾸지 않으며, 닫힌 패널의 늦은 import 결과를 반영하지 않는다. 잘못된 초안은 이전 결과를 유지하고 유효한 새 계산의 출처/예산/수치 실패는 이전 결과를 지운다. 전체 시각·값·설정·지문·정확한 IEEE 비트를 JSON으로 내려받는다.

## 테마·문자·블럭 표시

기본 다크는 검정/차콜, 라이트는 밝은 회색 표면이다. 애매한 짙은 파랑이나 순백을 기본 배경으로 쓰지 않는다. 선택 테마를 브라우저 preference에 저장한다. category 색은 포트·얇은 stroke·라이브러리 식별에 사용하며 글자를 대신하지 않는다.

| token | 현행 기본 |
| --- | --- |
| dark canvas / surface | `#111111` / `#1b1b1b` |
| light canvas / surface | `#e4e5e7` / `#ececee` |
| 본문 / 보조 / 큰 글자 | 1rem(기본16px) / .875rem(14px) / 1.125rem(18px) |
| heading / brand / 주요 결과 | 1.25rem / 1.5rem / 2rem |
| 한글·숫자 | Segoe UI·Malgun Gothic·Apple SD Gothic Neo·system fallback, font-synthesis:none |
| focus | 2px visible outline과 offset, 키보드 선택을 hover만으로 전달하지 않음 |

rare metadata의 .75rem token은 보조 맥락용이며 계산 값·필수 지침·축/단위·상태를 작은 글자로 숨기지 않는다. 테마별 text/line/accent·selected/error/disabled 상태와 125~200% 확대를 실제 관측한다. 기본 크기와 함께 font fallback·한글 line-height·숫자 폭·ellipsis의 전체 접근 경로를 검사한다.

캔버스 블럭은 종류 이름 하나와 의미 있는 핵심 값만 표시한다. `Gain`과 gain 숫자, `Constant`와 값처럼 읽는다. 한국어/영어 이름·‘배율’ 같은 설명·같은 숫자·아이콘을 블럭 안에 중복하지 않는다. 왼쪽의 굵은 category marking line은 없으며 stroke에 과하지 않은 색만 준다. 상세 자료형·단위·포트·초기값·수식·지원은 선택한 속성 패널과 결과에서 설명한다. [실제 BlockNode](../apps/web/src/components/BlockNode.tsx)와 [typed UI 회귀](../tests/m10-ui-values.test.ts)가 이를 구현한다.

실행 요청이 실제 Worker running 상태로 확인되면 좌상단 CalcWeave 로고에 은은한 흐름/pulse를 표시한다. paused·idle·failed에서는 움직임을 멈추고 `prefers-reduced-motion`을 따른다. 로고 animation만으로 실행·저장 성공을 주장하지 않는다. [RunBrand](../apps/web/src/components/RunBrand.tsx)와 [CSS](../apps/web/src/components/RunBrand.css)에 상태별 규칙이 있다.

## 파라미터·실행·결과

파라미터 입력은 label·단위·현재값·선택 가능 옵션·오류 이유를 보여 준다. 중간 숫자 입력 초안이 아직 유효하지 않으면 원래 모델값을 NaN으로 덮어쓰거나 실행하지 않는다. enum/typed/행렬/표/JSON fields도 실제 schema로 검증한다. dtype code와 real-world 값, Word/Fraction Length와 overflow, 계수 순서·상태 좌표, period/offset와 초 단위 Ts를 혼동하지 않는 문구를 사용한다.

idle/validating/running/pause-requested/paused/cancel-requested/completed/failed 상태를 실제 ack와 구분한다. pause·resume·cancel은 Worker가 수락한 상태에 맞춰 버튼과 로고를 바꾼다. 모델 초기화는 현재 도식을 지우는 동작과 구분한다. 정지 중 편집과 재개는 원래 실행 snapshot을 유지하며 새 설정을 이미 실행한 것처럼 표시하지 않는다.

결과는 현재·stale·취소·부분 실패를 구분하고 다음 정보를 연결한다.

| 결과 계열 | 표시할 내용 |
| --- | --- |
| scalar/array/typed | 전체 값·dtype/shape/unit·마지막 표본, 정확 code·IEEE special/−0·complex/string/enum 의미 |
| 시계열 | 실제 시작/종료 시각·표본 수·범위 조정·전체 수치 table과 CSV/typed JSON |
| solver | 출력 격자와 내부 step 차이, 실제 수락·거절·평가·event·간격, 실패 위치 |
| bus/messages | field/payload 계층·producer/sequence/priority/time·batch, legacy 숫자처럼 강제 표시하지 않음 |
| record/XY | bounded 기록·두 축과 unit·관측 시점, 보관된 값과 현재 transient를 구분 |
| stop/lifecycle | 정상 stopReason과 실패를 구분, adapter의 실제 initialized/terminated/reason |

긴 지연 모델은 scope 시간 범위를 바꾸어 관측한다. 화면 범위만 바꾸는 기능과 모델의 실행 stopTime을 바꾸는 기능을 명확히 안내한다. table 일부 pagination/표시100행 같은 UI 제한이 전체100샘플이라고 오인되지 않도록 실제 전체 수를 표시한다.

## Dashboard·지원표·해석

Dashboard control의 kind/min/max/step/choices·appearance/orientation과 indicator gaugeStyle/thresholds/labels를 실제 기능에 연결한다. live 입력은 이산 실행에서 다음 due에 적용되고 receipt가 생겨야 적용됨으로 표시한다. 예정 schedule·현재 UI 초안·실제 applied receipt를 구분한다. 복구/다운로드 모델에는 재생 가능한 event plan을 포함한다. 허용 작업 목록의 action button만 사용하고 arbitrary callback을 실행하지 않는다.

**CalcWeave 도움말**은 사용 안내·블록 찾기·파일·코드·앱 정보의 네 작업 중심 항목으로 구성한다. 첫 화면은 설치 없이 웹 브라우저에서 계산·시뮬레이션하는 CalcWeave 자체의 사용 흐름을 설명한다. 엔진 ID·개발 단계·검증 gate·원시 상한·목표 도메인 계획을 제품 소개에 나열하지 않는다. 블록 설명·입출력·설정·코드 내보내기를 먼저 보여 주고 ID·버전·자료형 선언은 접힌 기술 정보에서 확인한다. 현재 앱 버전과 문의·정책·백업 경로는 앱 정보에 둔다. 실제 확인한 브라우저 범위와 계산 상한은 읽기 쉬운 이름으로 별도 상세에서 확인할 수 있게 한다.

Simulink 관련 자료는 기능·파일 형식의 비교를 위한 참고이며 CalcWeave 실행의 필요조건으로 제시하지 않는다. 앱 정보의 닫힌 **호환성 참고**에서 원자료 비교와 확장 기능 상세를 열 수 있다. 원본385행과 registry337개의 구분·source ID·분류·선택 범위·모드·타깃·설정·외부 환경·검증 증거는 이 고급 참고에 유지한다. ‘공유 설정’, ‘독립 대체’, ‘조건부 어댑터’, ‘레거시/미지원’을 실행 성공과 같은 표시로 취급하지 않는다. 전체 옵션 동등 승인0·원본 전수 옵션 미검증과 실제 선택 범위367을 함께 제공한다. 같은 이름의 원자료도 바인딩/환경이 다르면 따로 조회한다.

해석 도구는 선택 expression의 실제 gradient·resolution 비교와 smooth plant operating point의 A/B/C/D를 설명한다. 필드가 있다는 이유로 선형화가 계산됐다고 표시하지 않으며 타깃/shape/interior·모드 조건의 진단을 먼저 보여 준다. solver·수치 알고리즘·원본 외부 환경의 미지원은 [기술 백서](01-technical-whitepaper.md)의 경계를 따른다.

## 백업·복구·가져오기·내보내기

저장 상태는 저장중/브라우저 저장됨/실패/다른 탭 변경을 구분한다. 문구 길이가 바뀌어 header와 캔버스 높이가 흔들리지 않게 한다. 도식과 포함 데이터의 일상적인 전달에는 `.cw.json`의 모델 다운로드·가져오기를 사용한다. **작업 공간 → 백업·복구** 화면은 작업 공간 백업과 복구 미리보기를 우선 보여 준다. 저장 상태·이전 정상 저장·읽지 못한 원본·로컬 진단은 닫힌 **저장 문제 해결**에서, 버전·SHA-256은 미리보기의 닫힌 **백업 검증 정보**에서 확인한다. **이 브라우저의 저장 데이터 삭제**도 닫힌 영역에 두며 대상 검토와 명시 확인의 두 단계는 유지한다. 다운로드 파일/다른 브라우저까지 지워졌다고 안내하지 않는다.

공개 키 지문과 일회용 서명은 파일의 출처를 별도 채널로 확인하려는 사용자를 위한 기능이다. 이를 기본 header에 독립 버튼으로 노출하고 세부 저장 진단을 한꺼번에 보여 주던 구성은 계산 작업에 비해 복잡했다. **작업 공간 → 고급 파일 → 서명된 모델 패키지**로 진입을 묶고 서명·지문 확인·migration 검토 절차는 유지한다. 서명은 작성자의 실명 인증으로 안내하지 않으며, 일반 모델 전달에 필요한 단계로 요구하지 않는다.

[작업 공간 메뉴](../apps/web/src/components/WorkspaceMenu.tsx)는 native details/summary를 사용한다. 외부 클릭·Tab으로 영역 이탈·Escape로 닫히며 외부 클릭의 기본 동작을 막지 않는다. 모달을 열기 전에 메뉴를 닫고 보이는 작업 공간 버튼으로 초점을 옮겨, 종료 후 숨겨진 메뉴 항목이 아닌 진입 버튼으로 돌아오게 한다. 좁은 화면에서는 팝업을 viewport 안에 배치하고 메뉴 내용이 가로로 넘치지 않게 한다.

코드 dialog는 TypeScript/Python/WASM/C·C++를 구분하고 현재 모델의 실제 타깃 진단을 먼저 보여 준다. unsupported를 빈 파일이나 성공 버튼으로 처리하지 않는다. archive의 코드·모델·manifest·예제·README와 완료 snapshot의 expected-output을 설명한다. 현재 모델과 결과가 다르거나 완료 결과가 없으면 expected-output을 포함하지 않고 이유를 표시한다. 단일 복사/다운로드와 실행 묶음을 구분한다. 모델/데이터/설명·서명 정보가 파일에 포함되므로 공유 전에 확인할 수 있게 한다.
