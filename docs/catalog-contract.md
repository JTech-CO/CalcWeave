# 수학·신호 확장 계약

2026-10-03 KST · 앱0.8.0 · 엔진0.8.0-catalog · 모델 schema1. 사용자가 선택한 수학·신호 중심 확장으로 기존74종에 실제 신규 연산64종과 시간 입력6종을 추가해144종을 제공한다. 상세 ID와 원자료 대응은 [확장 계획](block-expansion-plan.md)·[블럭 대응표](block-coverage.md)에 기록한다.

## 계산과 실행

새64종은 기본 수학/쌍곡선·다항식·불감대/실수 양자화·boolean 조건·통계 축약·벡터 연산·행렬 선택/결합/변환·고정 배열 입력이다. 단순 별칭이나 기존 옵션 프리셋을 새 계산으로 합산하지 않는다. 각 정의의 승인 포트·자료형·단위·형상을 컴파일하며 모든 지원 모드의 실제 원시 결과를 독립 fixture와 비교한다. 기본적으로 float64·boolean의 동종 scalar/vector/2D이며 각 연산별 입력 조건은 registry에서 확인한다. 통계 분산/표준편차는 전체 원소에 대한 모집단 값이다. index는 고정0-based 정수이고, 다항식 계수는 내림차순이며 Horner로 평가한다. 실수 Quantizer는 step과 ties-away-from-zero를 사용하며 기존 Fixed Quantize의 저장정수·반올림 계약과 구분한다.

시간 입력은 Chirp·Gaussian Pulse·Damped Sine·Exponential·Logistic·Sinc Pulse다. 절대 시각 seconds로 평가하며 이산 due tick과 연속 RK stage에 현재 시각을 전달한다. 정적 모드는 명시적으로 거부한다. Chirp는 Hz의 선형 주파수 sweep을 위상 적분하며0~duration 이후에는 최종 주파수를 유지하고 음수 시각에는 초기 주파수를 사용한다. Logistic는 안정된 지수 분기로 평가하며 정규화 Sinc의 중심 극한값은1이다. 벽시계·네트워크·외부 프로그램에 의존하지 않는다.

기존 블럭74종의 파라미터/기본값/범위·포트·모드·타입·형상·단위·샘플시간·상태·direct feedthrough와 export 대상은 유지한다. 새 Sign/mod/remainder/quantizer/predicate 등 시간변화 불연속 연산을 직접 연속 ODE 미분 경로에 연결하면 `UNREGISTERED_DISCONTINUITY`로 거부한다. 샘플링된 관측 결과는 허용하지만 미승인 zero-crossing 사건을 지원한다고 표시하지 않는다. Dead Zone은 값이 연속인 piecewise 연산이다. 연속 ODE 상태는 기존의 단위1 float64 scalar 범위다.

## 코드와 파일

TypeScript는 전체144종을 각 승인 모드로 내보낸다. 새70종을 포함한 모델의 타깃 버전은 `typescript-catalog-v1`이고 고정 실행 소스와 검증된 JSON 데이터를 포함한 import 없는 독립 코드다. 기존 블럭만 사용하면 이전 타깃 계약을 유지한다. Python의 승인51종은 유지하며 새70종과 연속/고급 미지원 모델에는 원본 노드 진단을 표시한다. ZIP README도 실제 타깃과 모드를 설명한다.

모델 패키지는 현재144종을 검사할 수 있도록 registry 상한을256으로 늘렸다. 실제 실행은 정확히 등록된144종과 버전으로 제한한다. 6MiB·깊이/값 개수·정확한 `local-model` 권한·hash·ECDSA 서명·독립 fingerprint 확인을 유지한다. 임의 코드/커널·권한·네트워크 참조는 수락하지 않는다. 선언형 모델과 native JSON만 공유하며 외부 형식 변환은 추가하지 않았다.

## 화면과 상한

예제32개를 기초7·신호 입력3·이산 상태6·연속/혼합9·데이터/도식3·행렬/표/양자화4로 분류한다. 표시 제목·설명·카테고리와 정확한 예제 ID를 우선 검색하고 표시 일치가 없을 때 블럭 ID로 검색한다. Enter/방향키/Escape와 IME를 구분하고 메뉴를 viewport 안에 배치한다. 빠른 추가의 K 및 예제 버튼의 문자 v는 제거하며 `Ctrl+K`와 도움말/접근성 설명은 유지한다. 캔버스의 종류 이름·핵심 값, 검정/밝은 회색 테마와 읽기 크기는 유지한다.

모델5MiB·깊이32·값100,000·블럭1,000·연결5,000, 신호1,024원소, 행렬 각축32, 실행 기록/상태/스텝·연산5천만·시간 예산을 유지한다. 다항식·convolution·sort·새 시간 입력 비용을 연산 예산에 반영한다. 입력 길이/옵션/정수/범위·형상·index·단위를 검증하며 정의역 이탈·0제수·비유한 값은 원본 노드의 `ModelError`로 중단하고 완료 표본을 보존한다. 사용자 텍스트는 일반 문자열/React escaped text와 JSON 데이터로만 처리한다.

## 원자료와 후속 범위

원자료385행/339이름은 보존했다. 추가 승인20행은 신규 계산 대응19행과 기존 Divide 추적교정1행이며 같은 이름의 중복 문맥도 각각 추적한다. 미구현251행과 외부 MATLAB/하드웨어·S-function·DAE·복소수·일반 fixed-point·일반 n-D·동적 index는 별도 계약이 필요하다.144개 registry 정의는 전체 Simulink 동등 구현을 뜻하지 않는다. M6의 도메인/공개 배포/실제 초보자 검증 조건은 유지한다.
