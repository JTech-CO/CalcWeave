# CalcWeave 화면 수정 — SANE 적용

> 버전: v0.4 · 2026-10-02 · M0 화면 수정 기준과 M1~M3 확장 기록

M1에서도 이 기준을 유지했다. typed 속성·전체 배열 표·빠른 추가·긴 블럭명을 추가한 화면 측정과 브라우저 27개 회귀 결과는 [M1 검증 기록](m1-validation.md)에 있다. 이하 M0 검사 수는 해당 수정 시점의 이력이며 최신 측정은 [화면 증거](evidence/sane-design-verification.json)를 따른다.

M2는 registry45종·실행묶음·일시정지/재개/초기화·주기/offset 필드를 추가하고 같은 읽기 크기·테마·좌우배치·최초맞춤 기준으로 다시 측정했다. 기존27개에 M2 기능6개·후속 캔버스 조작2개를 더한 브라우저35개와 화면측정이 통과했다. [FIR 화면](evidence/sane-m2-fir-result.png), [다중주기 화면](evidence/sane-m2-multirate-result.png), [M2 검증 기록](m2-validation.md)에 증거를 남겼다. paused 중 모드를 편집해도 현재snapshot의 재개 버튼을 보존하고 로고움직임은정지한다.

M3는 라이브러리 57종과 RK4·RK45, solver 설정·사건 목록·실패 부분 기록을 추가했다. 캔버스의 간결한 이름·핵심 값, 중성 다크·회색 라이트, 기본 글자 크기와 좌우 결과 패널은 같은 기준을 유지한다. 출력 격자와 내부 간격의 설명을 실행 설정 바로 옆에 제공하고 사건·횟수 상한은 펼침 영역에 둔다. 수락·거절·미분 평가·사건 횟수와 승인 간격 범위는 결과에서 확인하며 실패한 기록은 마지막 유효 부분 결과로 표시한다. 신규 수치·혼합 예제 8개와 독립 연속 TypeScript·manifest ZIP을 제공한다. 실제 회귀·화면 증거와 확인 범위는 [M3 검증 기록](m3-validation.md)과 최신 [디자인 측정](evidence/sane-design-verification.json)에 기록한다.

M3에서도 휠 버튼 드래그 이동, 왼쪽 드래그의 푸른 선택 사각형과 캔버스 Space 맞춤을 유지한다. 최초 복원 후 한 번 맞춘 뒤 일반 편집·실행은 viewport를 유지하고 입력·버튼·대화상자의 Space를 가로채지 않는다. 솔버 설정이 늘어났다는 이유로 패널 글자를 줄이거나 도식 블럭에 파라미터를 중복 표시하지 않는다. 이 자동 화면 검증을 실제 초보 사용자 조사나 접근성 인증으로 표현하지 않는다.

[SANE v1.0.0의 한국어 스킬](https://github.com/JTech-CO/SANE/blob/main/SKILL-KR.md)과 관련 디자인·검토 기준을 읽고 적용했다. 작업 캔버스의 우선순위, 읽을 수 있는 문자 크기, 정보 반복 제거, 역할이 있는 색상, 한글·숫자 렌더링을 이번 수정의 기준으로 삼았다. 사용자가 지정한 검정 계열 다크모드와 회색 라이트모드를 제품 결정으로 유지했다.

## 테마와 가독성

기본 테마는 검정·차콜 계열의 다크모드다. 라이트모드는 밝은 회색 표면을 사용한다. 선택한 테마는 `calcweave.theme`이라는 브라우저 설정으로 저장하고, 저장소 접근이 막혀도 편집기를 열 수 있다. 이 설정은 모델 JSON이나 계산 의미에 포함하지 않는다.

본문·입력·주요 조작은 1rem, 중요한 보조 라벨은 0.875rem을 기준으로 한다. 0.75rem은 실행 시간·버전처럼 비핵심 메타정보에만 사용한다. 좁은 화면에서는 패널과 버튼을 재배치하며 핵심 글자를 줄이지 않는다. 한글과 영문은 로컬 시스템 산세리프를 사용하고 숫자는 tabular 숫자로 정렬한다.

블럭명은 1.25rem(기본 20px), 핵심 숫자는 1.5rem(24px)로 표시한다. 그래프의 축 숫자를 SVG의 축소되는 좌표계에서 분리해 HTML 글자로 표시한다. 정적 계산의 한 점을 큰 그래프로 반복하지 않고 결과값과 수치 표를 제공한다. 자동 도식 맞춤은 최소 zoom 0.8을 사용해 블럭명을 최소 16px로 유지한다. 좁은 화면의 큰 도식은 이동해서 읽으며 사용자의 수동 확대·축소는 유지한다.

## 캔버스와 결과의 좌우 배치

데스크톱 중앙 작업 공간은 캔버스 왼쪽·계산 결과 오른쪽으로 배치한다. 결과 패널은 기본 320px, 넓은 화면에서 최대 420px 너비이며 캔버스와 같은 높이를 사용한다. 정적 계산도 같은 배치를 사용하고 결과·진단·그래프·전체 수치 표를 오른쪽에서 확인한다. 각 영역의 스크롤은 작업 공간 안에서 처리한다.

창 너비가 761px 이상이고 중앙 가용 폭이 44rem 이상일 때 좌우 배치를 적용한다. 1150px 이하에서는 라이브러리를 위쪽 가로 목록, 속성을 작업 공간 아래로 옮겨 태블릿에서도 좌우 배치를 확보한다. 더 좁은 화면이나 200% 글자 확대에서는 세로로 재배치해 글자 크기와 계산 정보를 보존한다. 모델 좌표와 연결을 바꾸지 않는다.

### 첫 로딩의 도식 맞춤

첫 로딩은 로컬 저장 복원을 끝내고, 현재 모델의 모든 블럭과 실제 캔버스 크기가 측정된 후 한 번만 도식을 맞춘다. 기본 예제가 먼저 렌더링되더라도 저장된 모델의 위치·종류를 기준으로 맞춘다. 모델 좌표와 undo 이력에 측정값을 기록하지 않는다. 기존 padding 0.12·최소 zoom 0.8·최대 zoom 1.05를 유지하며 큰 모델은 읽기 크기에서 이동해 확인한다.

사용자가 이후 이동·확대한 viewport는 일반 편집·계산·자동 저장으로 재설정하지 않는다. 빈 저장 모델은 맞춤 요청을 끝내므로 나중에 블럭을 추가할 때 화면을 자동 이동하지 않는다. 사용자의 `도식 맞추기`와 예제·파일·복구본 열기의 명시적 맞춤은 유지한다.

1440px·1920px에서 기본 모델 첫 로딩과 의도적으로 지연한 실제 IndexedDB 복원을 검증했다. 원점에서 멀리 있는 작은 도식의 전체 블럭·중심, 원래 모델 좌표 보존과 확대·이동 후 속성 편집·실행의 viewport 유지가 통과했다. [수정 화면](evidence/initial-canvas-fit.png)을 남겼으며 빌드와 전체 브라우저 회귀 27개가 통과했다.

### 캔버스 마우스와 키보드

휠 버튼을 누르고 드래그하면 도식 전체를 이동한다. 캔버스의 빈 곳에서 왼쪽 버튼을 드래그하면 푸른색 반투명 사각형이 표시되고, 범위에 들어온 블록을 선택한다. 블록 위의 왼쪽 드래그는 위치 편집, 포트의 클릭·드래그는 연결, Shift+클릭은 추가 선택을 유지한다. 휠 회전의 확대·축소도 유지한다.

캔버스·블록을 클릭하거나 키보드로 캔버스에 포커스를 둔 뒤 Space를 누르면 기존 읽기 크기의 도식 맞춤을 실행한다. React Flow의 기본 Space 이동 활성화는 해제했다. 입력 필드·버튼·대화상자에서는 Space의 기본 동작을 보존하고, 한글 조합·보조 키 조합·키 반복은 맞춤을 실행하지 않는다. 안내와 사용 방법에도 같은 조작을 표시한다.

[다크 선택 화면](evidence/canvas-selection-dark.png)과 [라이트 선택 화면](evidence/canvas-selection-light.png)은 실제 왼쪽 드래그 중 두 블록을 포함한 선택 범위다. 선택 중 viewport·모델 좌표 유지, 선택 블록 위의 휠 버튼 이동, Space의 포커스·입력 경계와 기존 초기 맞춤·다중 선택 복사/삭제를 브라우저에서 검증했다.

## 실행 로고의 펄스

계산·시뮬레이션 실행 시 CalcWeave 마크와 이름에 강조색이 순서대로 흐른다. 짧은 계산도 한 주기(1.4초)가 보이며 긴 계산에서는 반복한다. 실행 완료 표시는 엔진 결과가 도착하는 즉시 갱신하고, 남은 한 주기의 장식 효과가 완료를 늦추지 않는다. 취소·오류 때는 즉시 멈춘다. 새 실행과 컴포넌트 종료 시 남은 타이머를 정리한다.

`prefers-reduced-motion: reduce`에서는 움직임 없이 마크의 정적인 강조만 사용한다. 접근 가능한 계산 중 이름은 실제 `validating`·`running` 상태에서만 제공하며 장식 효과를 실행 상태로 해석하지 않는다.

## 블럭 표시 계약

캔버스 블럭의 정상 상태에는 **영어 블럭명 하나와 핵심 숫자 하나**를 표시한다.

M1의 boolean은 `true`/`false`, 배열은 `[n]` 또는 `rows × columns`로 요약한다. 상세 원소·수식·연산 설정·unit은 속성과 결과에서 확인한다. 숫자 파라미터가 없는 블럭은 이름만 표시한다.

| 블럭 | 기본 예시 | 숫자의 의미 |
| --- | --- | --- |
| Constant | `Constant` / `2` | 설정한 상수 |
| Input | `Input` / `1` | 실행 입력값 |
| Gain | `Gain` / `3` | 설정한 배율 |
| Unit Delay | `Unit Delay` / `0` | 초기값 |
| Integrator | `Integrator` / `1` | 초기값 |
| Display | `Display` / `6` | 현재 모델의 실행 결과. 없거나 오래된 결과는 `—` |
| Sum, Product | 이름만 | 숫자 파라미터가 없는 현재 계약에 값을 추가하지 않음 |

한영 이름 중복, 아이콘, 파라미터 제목, 장식 수식과 왼쪽 세로 마킹을 제거했다. 카테고리는 절제된 테두리 색으로 구분한다. 포트 ID·연결 동작은 유지하며 포트의 뜻은 접근 가능한 이름과 속성 패널에서 확인한다. 오류는 진단과 함께 `!`로 표시해 색에만 의존하지 않는다.

사용자가 작성한 블럭 label은 모델·속성 패널·모델 목록·접근 가능한 이름에 보존한다. 캔버스의 대표 이름은 블럭 종류다. 값 전체를 수정하는 입력과 연결·지원 모드 설명은 속성 패널에 둔다. 긴 숫자는 최대 8문자의 유효숫자·지수 표기로 요약하며 전체 숫자는 title과 접근 가능한 이름에 보존한다. 계산값 자체를 반올림하거나 변경하지 않는다.

## 결과의 정보 보존

M0의 최대 10,001개 시간 샘플은 그래프에서 모든 점을 그린다. 기존 일정 간격 요약이 짧은 피크를 놓칠 수 있는 문제를 제거했다. 수치 표는 처음·마지막 몇 행 대신 100행 단위로 전체 기록에 접근한다. 페이지 범위와 전체 샘플 수를 표시하며 경계 버튼은 비활성화한다.

표의 숫자는 읽기 좋은 표시값을 사용하고 원본 숫자는 셀 title에 보존한다. 원본 자릿수 복사·별도 결과 CSV 다운로드는 이번 화면 수정 범위에 포함하지 않는다.

## 확인 기록

렌더링 근거는 [디자인 측정 기록](evidence/sane-design-verification.json), [다크 화면](evidence/sane-dark-editor.png), [라이트 화면](evidence/sane-light-editor.png), [연속 결과](evidence/sane-continuous-result.png), [1920px 좌우 배치](evidence/sane-wide-editor.png), [900px 좌우 배치](evidence/sane-horizontal-tablet-editor.png)에 남긴다. `npm run build` 후 로컬 미리보기를 실행하고 `npm run verify:design`으로 다시 측정할 수 있다.

데스크톱·태블릿·390px·320px 화면, 200% 브라우저 확대에 해당하는 CSS viewport와 별도의 200% 글자 확대를 구분해 확인한다. 실제 한글 렌더링 폰트·본문 크기·축 글자·가로 넘침·블럭 마킹 제거를 기록한다. 이 범위의 확인을 접근성 인증이나 전체 제품 사용성 조사로 표현하지 않는다.

최종 빌드, 17개 브라우저 회귀 검사, 디자인 측정이 통과했다. 추가 검사는 데스크톱·태블릿 좌우 배치와 작은 화면의 세로 배치, 빠른 계산의 펄스 종료, 실행 중 펄스와 취소, 오류 시 종료, 모션 감소 설정을 확인한다. 실행 중 취소 검사는 실제 Worker의 진행 메시지를 유지하고 결과 전달만 지연해 완료 직후 버튼이 바뀌는 테스트 경합을 방지한다. 실제 취소 메시지 전송과 2초 내 취소·펄스 종료를 확인하며, 이 지연 검사를 엔진 성능 측정으로 사용하지 않는다.

확인한 주·보조·강조 텍스트의 배경 대비는 양쪽 테마 모두 4.5:1 이상이며 라이트모드 블럭 경계는 회색 캔버스·표면에 대해 3:1 이상이다. 200% 글자 확대에서 헤더와 패널 제목을 줄바꿈하고 블럭의 높이를 늘려 글자 잘림을 방지한다. 캔버스 안내는 도식을 가리는 오버레이 대신 하단에 배치한다. 포트의 실제 원과 연결선 끝을 정렬하고 24px 클릭 영역은 유지한다.

## M4 추가 화면 확인

M4는 위 시각·상호작용 기준을 유지하며 데이터·실험·대시보드·노트와 계층 화면을 추가했다. 결과 CSV 다운로드도 M4 범위에서 구현했다. [M4 측정 기록](evidence/m4-design-verification.json)은 기존 20개와 새 화면 40개를 합한 60개 관찰이다. 새 화면은 두 테마의 1440/1024/390/320px에서 글자 크기·대비·페이지 넘침·작업 공간 배치를 확인했다. 표와 탭은 필요한 영역 안에서 가로로 이동하며 페이지 전체를 넘기지 않는다. `npm run verify:design:m4`로 재현한다. 당시 기록은 보존하고 M4 화면은 `m4-sane-*.png`에 저장했다. 실제 전체 E2E 55개와 production build도 통과했으며 상세 범위는 [M4 검증 기록](m4-validation.md)에 있다.
