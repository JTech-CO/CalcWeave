# M6 로컬 베타 릴리스 후보 계약

작성일 2026-10-03 · 앱 0.6.0 · 엔진 0.6.0-m6 · 모델 schema 1

M6는 M1~M5의 수학 계약을 유지하고 공개 지원, 학습·접근성, 오프라인 정적 앱, 작업 공간 백업·복구, 로컬 운영과 배포 검증을 추가한다. 클라우드 M6-C는 선택하지 않는다. 계정·서버 API·결제·외부 분석·자동 오류 전송은 없다. M6 구현 완료와 실제 공개 출시 판정은 구분한다. 실제 초보자 F06 관찰과 공개 주소 검증은 자동 시험으로 대체하지 않는다.

## 공개 지원 정보

검색·지원표·컴파일러는 동일한 executable blockRegistry를 참조한다. 74개 블럭의 등록 모드·포트·매개변수·타입·형상·단위·표본 시각·상태와 TypeScript export를 보여준다. 등록된 inherited 계약은 컴파일 후 입력별로 결정되며 일반적인 broadcasting·복소수·nD 지원으로 해석하지 않는다. 기존 데이터셋 385개 항목의 구현 대응 상태를 새 블럭 완료로 승격하지 않는다.

## 오프라인 릴리스

최종 HTML·JS·CSS 및 정확한 정책 경로 4개만 SHA-256·바이트 길이 allowlist에 넣는다. 모델·CSV·결과·임의 URL·외부 응답은 캐시하지 않는다. 모든 파일 검증 후 마지막 완성 표시를 기록하며 설치 실패는 새 캐시만 제거한다. 대기 중인 업데이트는 저장 성공 후 명시적으로 활성화하고 요청 탭만 새로고침한다. 기존 탭의 늦은 코드 로드를 위해 이전 검증된 캐시는 남긴다. 앱 파일 캐시 삭제와 작업 자료 삭제는 별도다. 공개 루트 `/`와 secure context만 지원하고 개발 서버에서는 등록하지 않는다.

## 자료 유지와 진단

이전 정상 모델과 손상·미래 버전 원본은 검증 실패 시 덮어쓰지 않고 내려받기와 복구를 제공한다. 백업은 현재 모델의 데이터·서브시스템·대시보드·주석 및 최근 최대 5개 실행 기록을 포함하는 버전·해시 검증 JSON이다. 백업 파일 크기·깊이·객체 키·모델·실행 기록을 모두 검증한 후 단일 IndexedDB transaction으로 복구한다. 무효 파일은 기존 작업 공간을 변경하지 않는다. 탭별 revision 비교로 동시 저장 충돌을 검출하며 자동 병합하지 않는다.

로컬 데이터 초기화는 UI에서 2단계 확인하며 자료·설정 삭제 실패를 성공으로 표시하지 않는다. 로그는 최대 50개 고정 문맥·오류 코드·시각·엔진 버전만 저장한다. 오류 원문·스택·모델명·파일명·사용자 값·URL·헤더·시크릿·개인정보는 저장하지 않는다. 오류 전송과 원격 모니터링은 추가하지 않는다.

## 접근성과 실제 검증 범위

키보드로 캔버스/결과 이동, 블럭 선택, 설정 편집, 실행, 지원 검색과 관리 작업이 가능해야 한다. Dialog는 접근 가능한 이름·modal·focus containment·Escape·이전 focus 복원을 갖춘다. 상태 안내는 live region으로 제공하며 결과 표를 차트 대안으로 유지한다. 검은 다크/밝은 회색 라이트, 320px~넓은 화면과 200% 텍스트 확대에서 페이지 가로 overflow를 검사한다. 실제 검증 브라우저·버전과 관측 값을 기록하고 다른 브라우저 호환을 추정하지 않는다.

## 성능·안정성 측정 계약

고정된 로컬 Windows/Chromium·Node 환경에서 production dist를 측정한다. 100/1000 노드(스키마 최대1000)의 계산을 반복하고 모든 출력의 해석값을 확인한다. browser cold/warm load는 각각 5회, 취소는 최소 5회, 실행·저장 endurance는 30회 측정한다. 지연 p95와 강제 GC 후 JS heap 변화, long task와 오류를 기록한다. 기준은 로컬 cold load p95≤3000ms, warm≤2000ms, 1000노드 compile+run p95≤1000ms, 취소 p95≤1000ms, endurance retained heap 증가≤32MiB이다. 이 기준은 네트워크·전체 process 메모리나 실제 모바일 속도를 보장하지 않는다. 부족한 실제 기기/장시간 관찰은 출시 확인 항목이다.

## 배포와 출시 게이트

대상은 GitHub Pages·calcweave.com, 운영자 JTech-Co, 문의 jtech-bryan@proton.me이다. 정확한 저장소 URL·접근 권한·도메인 소유 확인 TXT·Pages 설정·A/AAAA/CNAME·HTTPS·실제 HTTP 헤더를 검증한 후 공개한다. 작업 폴더의 Git 원격 설정이나 DNS 확인 없이 소유·배포 성공을 주장하지 않는다. 빌드 내 CSP meta/Referrer policy와 로컬 preview HTTP 정책을 제공하지만 호스팅의 서버 헤더를 대신하지 않는다. 루트 custom domain 배포만 지원하고 `/repository/` 배포는 실패 처리한다.

정책 페이지는 실제 코드 흐름·로컬 저장·호스팅 트래픽을 구분한 초안이다. 문의 보유·호스팅 로그/국외이전 관련 운영 사실과 공개 적용일, 실제 사용자 F06 평가는 미확인 상태로 기록한다. 실제 배포하지 않은 주소의 보안·법률·운영 게이트를 PASS로 표시하지 않는다.
