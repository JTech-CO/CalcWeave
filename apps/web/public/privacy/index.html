CalcWeave가 처리하는 범위

앱에는 계정·프로필·결제·사용자 분석·광고 추적·자동 오류 전송 기능이 없습니다. 앱이 모델이나 데이터 파일, 계산 결과를 운영자 서버로 보내는 코드는 없습니다. 모델명·블럭명·수식·데이터 표에 개인 자료가 포함되면 브라우저와 사용자가 내보낸 파일에 남을 수 있습니다. 민감정보와 고유식별정보를 모델이나 데이터에 넣지 마세요.

로컬 저장 항목과 보유

모델 패키지와 생성한 코드에는 모델의 포함 데이터·설명도 들어갈 수 있으므로 파일을 전달하기 전에 내용을 확인하세요. 패키지 서명용 개인키는 파일을 만들 때만 메모리에서 사용하고 저장하거나 내보내지 않습니다. 공개키 지문과 서명은 공유 파일에 포함됩니다. 출처 확인과 파일 전달은 사용자가 직접 하며 앱은 키나 파일을 서버로 보내지 않습니다.

IndexedDB에는 현재 모델(포함 데이터·서브시스템·대시보드·주석), 이전 정상 저장 체크포인트, 복구용 원본, 최근 최대 5개 실행 기록이 저장됩니다. 오류 기록은 발생 시각·등록된 문맥·고정 오류 코드·엔진 버전만 최대 50개를 로컬 저장소에 저장하고 새 기록이 오래된 기록을 대체합니다. 오류 기록에 모델 내용·이름·값·메시지·스택·URL·메일 주소를 넣지 않습니다. 화면 테마 등의 설정과 백업 알림 시각도 브라우저 로컬 저장소에 저장합니다.

자료는 사용자가 삭제하거나 브라우저가 저장소를 정리할 때까지 해당 기기·브라우저에 남습니다. 서버에서 계정별로 보유하거나 다른 기기로 동기화하지 않습니다. 브라우저 저장은 앱 자체 암호화가 아니므로 공용 기기에서는 작업 후 로컬 데이터를 삭제하고 내려받은 파일도 직접 관리하세요.

열람·수정·내보내기·삭제

관리 화면에서 작업 공간을 백업하거나 복구하고 오류 기록을 내려받고 지울 수 있습니다. 캔버스와 설정에서 모델을 수정할 수 있습니다. 로컬 데이터 초기화는 현재 모델·체크포인트·복구 원본·실행 기록·오류 기록·설정을 삭제합니다. 브라우저 저장소 삭제도 가능합니다. 오프라인 앱 파일 캐시는 계산 자료와 별개이며 사이트 저장소 설정에서 삭제할 수 있습니다. 이미 내려받은 파일과 다른 기기·브라우저의 자료는 직접 삭제해야 합니다. 운영자는 사용자의 로컬 자료를 조회하거나 대신 복원할 수 없습니다.

호스팅 통신과 외부 링크

예정 호스팅은 GitHub Pages입니다. 온라인 접속과 앱 업데이트 시 정적 앱 파일을 받기 위해 호스팅 제공자와 통신합니다. GitHub는 서비스 사용 과정에서 IP 주소·기기 정보·접속 시각 등의 정보를 처리한다고 설명합니다. 이는 CalcWeave의 모델 전송이나 사용자 분석 기능과 구분됩니다. 자세한 사항은 GitHub 개인정보 처리방침을 확인하세요. 외부 문서 링크나 이메일을 직접 열면 해당 제공자의 처리방침이 적용됩니다.

공개 배포 전 확인할 사항

현재는 로컬 베타 후보 문서입니다. 정확한 저장소, 도메인 연결, 호스팅 로그의 운영자 접근 범위·보유기간과 처리위탁·국외이전의 해당 여부, 이메일 문의 처리 항목·보유기간·메일 제공자 및 적용되는 처리 근거를 확인한 후 공개 방침을 확정해야 합니다. 이 내용은 확인 완료로 간주하지 않습니다. 문의 메일에 포함할 정보는 사용자가 선택하며, 앱은 메일 내용이나 첨부 파일을 수집하지 않습니다.

개인정보 관련 문의와 권리 행사는 JTech-Co 문의로 연락할 수 있습니다. 개인정보 침해 상담은 개인정보 포털과 KISA 개인정보침해 신고센터를 이용할 수 있습니다.

생성한 문서는 초안이며 법률 자문이 아닙니다. 개인정보 처리방침은 실제 운영 형태와 일치해야 하며, 실사용자 개인정보를 처리하기 전 전문가 검토를 권고합니다.
