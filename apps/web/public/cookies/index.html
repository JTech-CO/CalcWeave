현재 앱의 저장 방식

CalcWeave 앱 코드는 쿠키를 생성하지 않습니다. 광고·마케팅·방문자 분석 SDK와 선택적 추적 도구도 없습니다. 현재 기능에 선택적 쿠키 동의 배너를 추가하지 않았습니다. GitHub Pages 호스팅 응답의 쿠키·헤더 확인 결과는 릴리스 배포 검증 기록에 남깁니다. 앱의 저장 항목과 호스팅 제공자의 통신 기록은 구분합니다.

IndexedDB와 설정

모델·포함 데이터·최근 실행·체크포인트·복구 원본은 기기의 IndexedDB에 저장합니다. 제한된 오류 기록, 백업 알림 시각과 테마 등 화면 설정은 로컬 저장소에 저장합니다. 용도는 작업 유지, 장애 복구와 화면 설정이며 광고나 방문자 추적이 아닙니다. 관리 화면의 로컬 데이터 초기화 또는 브라우저의 사이트 저장소 삭제로 제거할 수 있습니다.

오프라인 정적 캐시

Service Worker는 확인된 앱 HTML·JavaScript·CSS와 정책 페이지를 버전별 정적 캐시에 저장합니다. 모델·실행 결과·사용자 파일·임의 URL·외부 응답을 캐시에 추가하지 않습니다. 이전 탭이 필요한 코드 조각을 잃지 않도록 이전 릴리스 캐시는 자동 삭제하지 않습니다. 캐시 공간을 회수하려면 모든 CalcWeave 탭을 닫은 후 브라우저 사이트 저장소를 삭제하세요. 이 작업은 로컬 계산 자료도 지울 수 있으므로 먼저 백업하세요.

저장 거부와 한계

브라우저에서 사이트 저장을 막거나 시크릿 모드로 이용하면 저장·복구·오프라인 기능이 제한될 수 있습니다. 파일로 내보내기를 사용할 수 있으며 브라우저의 저장소 정책에 따라 동작은 달라집니다. 추적 도구를 도입할 경우 수집 목적과 선택·철회 절차를 먼저 변경하고 문서 버전에 표시합니다.
